# 合成软件测试示例 — 非实验数据

这些 CSV 由公开数学公式构造，用于验证读取、峰提取、已声明质控和线性拟合的程序行为。它们不是仪器观测，不能用于证明实际传感器灵敏度、检出限或化学峰归属。

电位以 V 表示，取值为 0 到 0.6，步长 0.002。每条曲线使用相同背景和三角峰：

```text
background(E) = 0.3 + 0.1 * E
peak(E) = max(0, 1 - abs(E - 0.3) / 0.09)
current(E, c) = background(E) + (0.4 + 2 * c) * peak(E)
```

浓度 `c` 分别为 0.5、1、2 和 3 mM，每个浓度仅有一条合成曲线。响应的单位是 uA，预期峰电位为 0.3 V，预期峰到基线的距离为 `0.4 + 2*c`，拟合斜率为 2.0 uA/mM、截距为 0.4 uA、R² 约为 1。

这是一组无随机噪声的软件夹具；其 SNR 不代表真实实验信噪比，单次曲线也不支持估计重复测量 SD。manifest 中的背景锚区不包含三角峰，所有曲线共用相同窗口。预期结果见 `expected.json`。

在仓库根目录依照主 README 的命令运行。输出必须放在本示例和技能目录之外。先使用 `--prepare-only` 检查准备阶段，再在具备 OriginPro 2021 的电脑上验证完整流程。
